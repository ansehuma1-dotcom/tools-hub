How to use the Password Generator

Choose a length and which character types to include, such as upper-case letters, lower-case letters, numbers and symbols, then generate a password. The tool creates it at random in your browser, so no one else sees it and nothing is stored. Copy it straight into a password manager rather than writing it on paper or sending it by message.

Example

A 16-character password mixing all four character types is far stronger than a short word with a number at the end, because every extra random character multiplies the guesses an attacker must try. Use a different password for each important account, and turn on two-factor authentication where it is offered, because even a strong password alone is not enough.

Storing passwords safely

A strong password only helps if it is stored safely and used once. A password manager can remember a different random password for every site, so you only need to remember one strong master password. Never reuse a password from an important account, such as email or banking, on a less important site, because a breach at the small site would then give an attacker the key to the important one.
