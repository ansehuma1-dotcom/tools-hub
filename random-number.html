How to use the Random Number Generator

Enter the smallest and largest numbers you want, choose whether repeats are allowed, and generate. With repeats allowed, the same number can appear more than once; without repeats, each number can appear only once, which is what you want for a draw or a raffle. The result is produced in your browser, so it is ready at once.

Example

To pick a winner from 30 entries, generate one number between 1 and 30. To pick a lottery-style set, generate six numbers between 1 and 49 without repeats. Teachers use it to pick students fairly, game groups use it for dice-like rolls, and organisers use it for prize draws where everyone should have an equal chance.

Fair use

Random numbers from this tool are fine for everyday draws, classroom picks, games and raffles, where everyone should have an equal chance. They are not suitable for gambling, lotteries with real money, or security purposes, which need audited, certified random systems and proper oversight. For a public draw, generate the number in front of witnesses or record the screen, so the result can be seen to be fair.
