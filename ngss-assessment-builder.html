Enter your standard and topic to build a classroom-ready 3D assessment package. This is an original framework tool — it does not check the official NGSS database, so please verify your standard's SEP, DCI and CCC before use.

Checking your assessment

Before using an assessment package, read the performance task as a student would and try to answer it yourself, checking that the phenomenon is clear, the data or evidence is actually provided, and the rubric levels describe observable work rather than vague effort. Ask a colleague to read it too, because a second reader often spots a missing instruction or an unclear expectation. Keep the formative storyline steps in order, so each step builds on evidence from the previous one.
